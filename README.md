## O que fazemos

Criamos aplicativos de gestão para pequenas e médias empresas que ainda controlam o dia a dia em planilhas, cadernos e mensagens. Cada sistema é desenhado em cima do jeito de trabalhar do cliente, e não o contrário.

| | |
|---|---|
| 🧭 **Sob medida** | As regras do negócio do cliente viram as regras do sistema |
| 📱 **Em qualquer aparelho** | Funciona no navegador e instala como aplicativo no celular e no computador |
| ⚡ **Em tempo real** | O que uma pessoa muda aparece na hora para toda a equipe |
| 🔒 **Seguro** | Perfis de acesso, senha forte e dados protegidos, com cópia de segurança diária |
| 🛠️ **Ajustável** | O próprio cliente adapta nomes, etapas e cadastros, sem depender de programador |

## Produtos

### 🩴 Solado

Pedidos, produção e montagem para fábricas de solas e chinelos. Acompanha cada pedido da entrada até a entrega: fila de produção, máquinas, montadores, estampas, relatórios e notas de entrega.

## Como trabalhamos

1. **Ouvimos** como a empresa funciona hoje.
2. **Montamos** o sistema com os cadastros e as regras dela.
3. **Publicamos** na internet, com endereço próprio e acesso por perfil.
4. **Acompanhamos**: melhorias, novos usuários e suporte.

## Tecnologia

Aplicações web leves, sem instalação nos aparelhos e sem loja de aplicativos. Atualizar é publicar: todos recebem a versão nova ao abrir o sistema.
